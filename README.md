# Object Oriented Programming

A collection of laboratory work and assignments completed as part of the **Object Oriented Programming (OOP)** course. The repository focuses on applying object-oriented programming concepts through practical programming exercises and larger assignments.

## Overview

The coursework covers the application of object-oriented programming principles to develop structured, modular, and reusable software. The repository contains laboratory exercises along with three assignments that progressively apply OOP concepts to different programming problems.

## Assignments

### Assignment 1 — Matrix Manipulation

An implementation focused on **matrix manipulation**, providing practical experience with organizing matrix-related operations within an object-oriented program.

### Assignment 2 — Game Development

A small game developed using **provided utility components**. The assignment focuses on using existing utilities together with object-oriented programming concepts to build the required game functionality.

### Assignment 3 — Employee Management System

An **Employee Management System** developed with an emphasis on **modular code organization**. The assignment applies object-oriented design to structure the system into separate, manageable components.

## Laboratory Work

The `oop labs` directory contains the practical laboratory exercises completed throughout the course. These exercises provide hands-on practice with object-oriented programming concepts and their implementation in code.

## Key Areas

The coursework provides practical experience with:

* Object-oriented program design
* Classes and objects
* Encapsulation and modularity
* Code organization and reuse
* Applying OOP concepts to problem solving
* Working with existing utility components
* Designing larger programs using separate modules
* Building software systems around real-world entities

## Learning Outcomes

Through the laboratory work and assignments, this coursework provided experience in:

* Designing solutions using object-oriented programming principles
* Structuring programs into reusable and maintainable components
* Applying OOP concepts to different types of programming problems
* Developing small applications and systems using object-oriented design
* Organizing larger programs into modular components
